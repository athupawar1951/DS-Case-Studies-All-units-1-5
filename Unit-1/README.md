# Unit 1: Divide and Conquer and Greedy Strategies

This folder contains two Data Structures case studies implemented in Python.

## Case Study 1: E-commerce Product Sorting
This program uses the Merge Sort algorithm to sort products by price. Merge Sort follows the Divide and Conquer strategy.

## Case Study 2: Google Calendar Activity Selection
This program uses a Greedy strategy to select the maximum number of non-overlapping activities from a list of events.

## Files
- `Case-Study-1-Ecommerce-Product-Sorting.md` — report for the product sorting case study
- `ecommerce_product_sorting.py` — Python implementation of Merge Sort
- `Case-Study-2-Google-Calendar-Greedy.md` — report for the activity selection case study
- `google_calendar_greedy.py` — Python implementation of the Greedy activity-selection algorithm

## How to Run
Use Python 3 and run each command from this folder:

```bash
python ecommerce_product_sorting.py
python google_calendar_greedy.py
```

These are small educational examples. The calendar program demonstrates activity selection and is not Google's actual scheduling algorithm.
